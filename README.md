# استودیو تولید ریلز و کارت استارتیچ | Starteach Reel & Card Studio Pro

یک ابزار حرفه‌ای برای طراحی و تولید محتوای بصری مخصوص شبکه‌های اجتماعی.

## ویژگی‌ها

- ✅ **کاملاً آفلاین**: بدون نیاز به اینترنت کار می‌کند
- ✅ **ذخیره‌سازی محلی**: تمام تنظیمات در مرورگر ذخیره می‌شود
- ✅ **ریسپانسیو**: بهینه‌شده برای موبایل و دسکتاپ
- ✅ **ماژولار**: کد تمیز و قابل توسعه
- ✅ **بدون وابستگی خارجی**: همه کتابخانه‌ها داخل پروژه هستند
- ✅ **سازگار با GitHub Pages**: آماده انتشار روی گیت‌هاب پیجز

## فایل‌های پروژه

- `index.html` - فایل اصلی HTML
- `tailwind.min.js` - کتابخانه Tailwind CSS (لوکال)
- `html2canvas.min.js` - تبدیل HTML به تصویر
- `gifshot.min.js` - ساخت GIF متحرک
- `fonts.css` - تعریف فونت‌های فارسی
- فونت‌های فارسی: Vazirmatn, Shabnam, Lalezar
- فونت‌های انگلیسی: Inter, Fira Code

## نحوه استفاده

1. فایل `index.html` را در مرورگر باز کنید
2. یا پروژه را روی GitHub Pages آپلود کنید

## انتشار روی GitHub Pages

1. این مخزن را به GitHub پوش کنید
2. به Settings > Pages بروید
3. Branch را روی `main` و folder را روی `/ (root)` تنظیم کنید
4. سایت شما در آدرس `https://username.github.io/repo-name` قابل دسترسی خواهد بود

## تکنولوژی‌ها

- HTML5
- CSS3 (Tailwind CSS)
- JavaScript (Vanilla ES6+)
- LocalStorage API
